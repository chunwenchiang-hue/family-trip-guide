# 同行完整操作流程：線上使用與主揪備份

適用於同行指南更新及出發前複查。預設同行直接用線上版，主揪下載備份；沿用可靠入口、原預約、PDF和QR。不要求每團都建網站、備忘錄或音訊，缺工具時給可用替代。當次明確要求全員離線或目的地弱網時，才把下列備份流程套給相應旅伴。

## 從旅客第一步開始

預設實際順序：精簡備忘錄／共用說明 → 點文字入口或掃原QR → 選日期 → 看行程、集合與交通 → 在對應景點聽女聲／溝通卡播外語 → 查預約與正式票券 → 外開導航／切App再返回。全程不先下載整份HTML，不先閱讀版本或試聽公告。

外層入口卡只留名稱、日期、單一網址／QR及必要提醒；原預約與附件放可收合備查。先保存本文與附件基準再局部調整；不覆寫整則而丟PDF、QR或收據。更新說明放主揪紀錄，同行首頁不堆女聲換版、檔名大小或製作中資訊。同手機不能掃自己的QR時提供直接可點連結；圖檔解碼與相機實掃分記。

首頁只給日期與當下任務，景點導覽留對應日期的景點卡，不放集中故事／試聽入口。使用者按景點播放即可，不假定定位抵達；線上音檔按需載入，不背景抓整個離線包。中文女聲與問路外語各自驗證，不能因刪男聲試聽公告就刪掉真正的問路男聲。

## 主揪下載入口與版本辨識

此節適用主揪／協助者或當次指定的離線使用者，不是一般同行首頁步驟。

- 另有易取用的備份入口；版本、更新日期、檔名、大小與下載教學放此頁或交付說明，首頁不宣傳。獨立URL不是私人權限，敏感原件沿用適當受眾。
- 備份頁與檔名有一致、可辨認版本／日期，例如虛構的 `主揪備份_2027-04-08_v3.html`；下載等待、去哪找檔案、如何重開有短說明，避免誤開舊檔。
- 由正式備份入口實際下載，核對檔名、內容與版本；用雜湊／位元比對確認本次產物。工具若忽略下載檔名或被阻擋，分記限制，不把本機原檔當正式下載驗證。
- 網站更新不會改已保存HTML；只通知持有備份者重存。未變PDF與票券可沿用，有版本落差則說最新依據，不要求全團重下。

## HTML預覽、單檔與備援

手機「檔案」或聊天App預覽可能不支援JavaScript、音訊、剪貼簿與返回；下載完成／能看文字不等於離線就緒。記實際App、播放進度與使用者聽感。不能互動時用線上入口、已同步文字、已存PDF、正式票券與紙本；不保證手機瀏覽器能直接開本機HTML。

主揪單檔要包含必要音訊、圖片、摘要、文字與控制；若仍用相鄰檔案，需完整打包或改內嵌，不能把線上音檔路徑當離線成功。單檔「取得更新」回穩定備份入口，不指向不存在的相對bin／HTML。外開導航、官網與即時交通仍需網路。

不繞過工具對file協定、離線或手機操作的限制；完成可做的內容比對和線上測試，分別記錄，不能冒稱真離線通過。

## 預約與播放的現場可用性

用日期、店名、代表人及單號搜尋，測複製、放大與關閉。無獨立預約號時從原件核對姓名、時刻、人數，放摘要及工作人員卡；收據仍叫收據號，拆單全部顯示。正式憑證沿用授權位置，不把主揪登入變成唯一取得方法。

在相應景點卡手動播放，觀察實際時間進展，測暫停、續播、重聽、切頁停止、外語互斥。音色由使用者確認；解碼／桌面播放不代表手機親耳通過。導航返回保持原日期、位置與展開狀態。
