# 同行完整操作流程：入口、下載與手機實測

適用於製作或更新同行指南，以及出發前從旅伴角度複查。沿用既有可靠入口、平台與預約；不要求每團都建網站、備忘錄或音訊。沒有的功能從清單移除並提供合適備援。

## 從旅客第一步開始

按真實順序操作：原備忘錄／共用說明 → 點入口或掃原QR → 辨認版本 → 下載 → 找到並重開檔案 → 試播放／查預約 → 切換App返回 → 關網後離開再重開。別只逐頁看畫面。

備忘錄或共用說明頂端放新版入口、變更摘要與需重新保存哪些檔。更新原筆記時優先局部插入，先保存本文及附件基準；不可整則覆寫而弄丟PDF、QR或收據。若依指示保留舊HTML附件，直接標明舊版並指向最新版。沒有權限修改筆記時交付可貼上的文字，明示未同步。

同一支手機不方便用相機掃自己的QR時提供可點文字連結；相機測試可掃另一台裝置或紙本。同行QR、正式車票／入場QR用途分明。QR解碼成功與相機實掃成功分開記。

## 下載入口與版本辨識

- 首頁上方有明顯下載入口，不必滑過所有日期。附近能找到試播、預約與簡短下載教學；保留今天、集合及求助的易用性。
- 頁面與下載檔名使用同一可辨認版本或更新日期，例如 `同行指南_2027-04-08_v3.html`；這是虛構範例，不固定格式。重要更新也可加「自然女聲」等旅客看得懂的變更詞，不只顯示內部提交碼。
- 提示預估檔案大小、等下載完成、去哪裡找檔案、如何重開；網路或裝置可能產生重複檔名，要讓旅客能辨認正確新版。長操作細節可展開。
- 先驗證實際下載的檔名、內容與版本，再提醒重新下載。正式網站更新不會改動已保存的HTML。原PDF或票券未變時直接說可沿用；有版本落差則指明差別與最新依據。
- 下載連結需從原正式網址操作；網頁與離線別名應一致。用雜湊或位元比對確認正式下載檔來自本次產物，不能只驗本機原檔或發布結果。下載工具若不遵循檔名屬性，記它與旅客正常點擊的差異。

## HTML預覽、單檔與備援

手機「檔案」或聊天App預覽可能只顯示文字，不能假定支援JavaScript、音訊、剪貼簿或返回。能開啟不等於能互動，下載完成也不等於離線就緒；先記實際開啟App，再看播放進度、按鈕與使用者聽感。

可建議改用正常手機瀏覽器開正式網址下載，但不保證手機瀏覽器能直接開本機HTML。無法互動時給可用替代：連網正式入口、已同步的原生文字、已下載PDF、正式票券及必要紙本；音訊無法離線使用就明列待處理，不宣稱已有完整語音備援。

檢查單檔包含必要音訊、圖片、預約摘要、文字稿與控制腳本；離線檔仍指向相鄰音檔或下載檔時，要一併打包、內嵌或改成明示需連網的更新入口。已保存HTML的「取得最新版」應回穩定線上下載區，不指向不存在的相對 `.bin`／HTML檔。外開導航、官網、即時交通標需網路；原PDF和正式憑證另列保存要求。

工具或政策不允許本機檔直開、切離線或操作手機時，保留限制，完成可做的內容比對與網頁測試；不能換隱藏方式繞過限制或把這些證據冒稱真離線成功。

## 預約與播放的現場可用性

用日期、店名、代表人及單號搜尋，測複製與放大／關閉。無獨立預約號時，由原件核對姓名、日期時間、人數，寫到摘要與給工作人員看的卡；收據號仍叫收據號。拆單完整顯示每筆及總人數。原件可在適當授權位置，別改成必須主揪登入的唯一入口。

播放要看實際時間進展，再測暫停、續播、重聽、切頁停止及與外語音訊互斥。音色聽感由使用者實際確認；檔案解碼與桌面播放不代表手機親耳通過。返回行程及外開Maps後返回，應保留原日期、位置和展開狀態。

## 逐人親手實測範本

把下列文字換成當次實際版本、檔名、日期與範例預約；事前預留下載時間，機場只複習。每位旅伴自己操作約五分鐘，較慢或有協助需求者另留時間。

```text
同行手機實測｜版本：〔當次版本〕｜下載檔名：〔當次檔名〕
□ 入口：同步共用說明／備忘錄，點文字連結，或掃另一裝置／紙本的原QR；看到指定版本並符合約定登入方式。找到PDF、正式憑證與求助方式。
□ 下載：等檔案下載完成，到自己的下載位置找到正確新版；離開後重開。只顯示文字、按鈕沒反應時記開啟App，改用已提供的備援並請協助。
□ 聲音（有提供時）：親耳試一段導覽及外語朗讀；測暫停、續播、重聽、切頁停止、不重疊；確認耳機／藍牙音量。
□ 預約與返回：找當日預約、代表人及所有拆單；試複製、放大／關閉、搜尋一筆預約；返回行程、外開導航再返回，仍在原日期位置。
□ 真離線：飛航模式＋關Wi-Fi，離開App再重開已保存指南、文字／PDF及必要音訊與靜態地圖。官網與新算導航需網路，不列離線通過項。
□ 正式憑證：找到本人每程車票／入場憑證，核對日期、人數／座位及報到要求，另存離線或紙本。同行QR與普通單號不能取代票券。
不能完成時回報：手機型號／開啟App／版本／卡在哪一步。未親手確認的項目保持待測，找協助者或使用已驗證備援。
```
